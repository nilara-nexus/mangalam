மங்கல அழைப்பு (Mangala Azhaippu) – Wedding invitation design store
Open index.html in a browser (internet needed once for Bootstrap 5 / fonts CDN).
Pages: index, templates, product, packages, about, contact, cart, signin, signup, account.
Data: localStorage per user (cart, wishlist, orders, callbacks). Demo coupon: TAMIL10.
Change phone number: PHONE / PHONE_TXT at top of assets/js/app.js.
Regenerate artwork: gen_assets.py (Python + Pillow + numpy + ffmpeg).
